# V3ST design system

**Interim, 2026-11-18.** The visual system is being rebuilt by the [landing redesign plan](docs/superpowers/plans/2026-11-18-v3st-landing-redesign.md). Task 13 of that plan rewrites this file from the built result.

Until then, every token, type size, motion number and fallback comes from the [redesign specification](docs/superpowers/specs/2026-11-17-v3st-landing-redesign-design.md): §Visual system, §Katana behaviour contract and §Accessibility and fallbacks. The approved look is the [approved mock](docs/superpowers/specs/assets/2026-11-17-v3st-landing-approved-mock.png).

The previous light ivory system is retired. Don't reuse it: forest green `#166534`, ivory canvas `#F7F8F2`, Geist, and the light-only rules.

Still true while the rebuild runs:

- **One theme, now dark.** Tokens live in `@theme static` in `src/styles/globals.css`. There is no Tailwind configuration file, no theme provider and no toggle.
- **Primitives.** The primitives in `src/primitives/` are generated by shadcn and restyled in place: Button, Badge, Card, Tabs, Sheet, Skeleton. Keep their files, exports and APIs. Their shadcn colour names become aliases of the new tokens (plan Task 1).
- **Icons and logos.** UI icons come from `@phosphor-icons/react/dist/ssr`, in regular weight, `aria-hidden` beside text. Real logos are official local files with recorded provenance, never redrawn.
- **This file is the design system.** Never create a file named `DESIGN.md`: on case-insensitive filesystems it collides with `Design.md`, the product architecture.
